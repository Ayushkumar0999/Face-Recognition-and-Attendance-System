# Face Recognition and Attendance System

## 📌 Project Overview

The **Face Recognition and Attendance System** is an automated attendance management application that uses facial recognition technology to identify individuals and record their attendance.

The system captures a person's face through a webcam, matches it with previously registered face data, and automatically marks attendance with the corresponding date and time.

This project helps reduce manual attendance work, saves time, and improves accuracy in attendance management.

## 🎯 Features

- **Face Detection:** Detects human faces using a webcam.
- **Face Recognition:** Identifies registered individuals through facial features.
- **Automated Attendance:** Automatically marks attendance after successful recognition.
- **Real-Time Processing:** Recognizes faces using a live camera feed.
- **Attendance Records:** Stores attendance details with date and time.
- **User-Friendly Interface:** Simple and easy-to-use application.

## 🚀 How It Works

1. Register a person's face in the system.
2. Capture and store face images.
3. Start the webcam.
4. The system detects and recognizes the face.
5. If the face matches a registered person, attendance is automatically recorded.
6. Attendance is saved with the person's name, date, and time.
